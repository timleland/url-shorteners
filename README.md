# URL Shorteners

[![List](https://img.shields.io/badge/list-950%2B%20shorteners-blue)](./list.txt)
[![License](https://img.shields.io/badge/license-MIT-green.svg)](./LICENSE)

A curated list of URL shortener services, link management platforms, self-hosted URL shorteners, and deprecated short URL services.

This repo combines two things:

- A human-friendly awesome list of notable URL shortener tools and services.
- A larger raw dataset of 950+ shortener domains in [list.txt](./list.txt) for link expansion, redirect analysis, and shortener research.

## URL Shortener Services

- [T.LY](https://t.ly) - World's Shortest URL shortener with branded links, QR codes, bio links, and analytics.
- [Bitly](https://bitly.com) - Popular URL shortener with branded links, analytics, QR codes, and campaign tools.
- [3.ly](https://3.ly/) - Short URL service with custom links, QR codes, and click statistics.
- [g2g.to](https://g2g.to/) - Short URL service with a compact branded domain.
- [jpeg.ly](https://jpeg.ly/) - Short URL service with a memorable short domain.
- [BL.INK](https://www.bl.ink) - Enterprise-focused link management platform for branded short URLs.
- [Cuttly](https://cutt.ly) - URL shortener with link customization, QR codes, and click tracking.
- [is.gd](https://is.gd) - Minimal free URL shortener with a simple API.
- [JotURL](https://joturl.com) - Link management and tracking platform for marketers and teams.
- [Kutt](https://kutt.it) - Open-source URL shortener with both hosted and self-hosted options.
- [LinkSplit](https://linksplit.io/url-shortener) - Shorten links and split traffic across multiple destinations.
- [lstu](https://lstu.fr) - Simple open-source shortener with an official public instance.
- [Ow.ly](https://www.hootsuite.com/pages/owly) - Hootsuite's URL shortener for social media publishing workflows.
- [Rebrandly](https://www.rebrandly.com) - Branded link platform focused on custom domains and campaign tracking.
- [Short.io](https://short.io) - Custom-domain URL shortener with routing rules, analytics, and team features.
- [shorturl.ly](https://shorturl.ly/) - Short URL service with a straightforward branded domain.
- [Switchy](https://switchy.io) - Smart link shortener with retargeting, UTM builder, and deep customization.
- [T2M](https://t2mio.com) - Short URL and QR code platform with analytics dashboards.
- [Tiny.cc](https://tiny.cc) - Long-running short link service with custom aliases and reporting.
- [TinyURL](https://tinyurl.com) - One of the best-known URL shortener services for fast, simple short links.
- [urlr.me](https://urlr.me/en) - Reliable URL shortener with custom aliases and API access.
- [v.gd](https://v.gd) - Simple and fast shortener related to `is.gd`.
- [zoomto.me](https://zoomto.me/) - Short URL service for quick, readable links.

## Self-Hosted and Open Source URL Shorteners

- [Eastlake](https://github.com/Likenttt/eastlake-cloudflare-worker-short-url) - Short URL system built on Cloudflare Workers.
- [Kutt](https://kutt.it) - Popular open-source shortener that can be self-hosted or used as a service.
- [lstu](https://lstu.fr) - Open-source shortener with a maintained public instance.
- [Polr](https://polrproject.org) - Modern self-hosted shortener for branded links and analytics.
- [pygmy](https://github.com/amitt001/pygmy) - Feature-rich open-source URL shortener and analytics platform written in Python.
- [reduced.to](https://github.com/origranot/reduced.to) - Open-source shortener with analytics and management features.
- [san.aq](https://github.com/neutronscott/sanaq) - Open-source shortener with an HTTP API and CLI-friendly workflow.
- [shlink](https://shlink.io) - Mature self-hosted URL shortener with APIs and detailed stats.
- [Sink](https://github.com/ccbikai/sink) - Cloudflare-based shortener with analytics.
- [YOURLS](https://yourls.org) - Classic self-hosted URL shortener used for custom branded links.

## Deprecated, Unavailable, or Historical Shorteners

- [cutit.org](https://cutit.org) - Historical shortener with no working public app observed on April 16, 2026.
- [git.io](https://git.io) - GitHub shortener that no longer accepts new links.
- [goo.gl](https://blog.google/technology/developers/googl-link-shortening-update/) - Google shortener deprecated in 2018; many legacy goo.gl links were retired after August 25, 2025.
- [hoy.kr](https://hoy.kr) - Former shortener domain that currently resolves to a parked domain page.
- [LiveChat URL shortener](https://www.livechat.com/url-shortener/) - Former shortener page that now redirects to LiveChat's UTM Builder.
- [me2.do](https://developers.naver.com/notice/article/17062) - NAVER short URL service scheduled for shutdown on December 2, 2024 and no longer available.
- [s2r.co](https://s2r.co) - Historical shortener domain that currently redirects into a parked or ad-style landing flow.
- [soo.gd](https://soo.gd) - Shortener currently showing a maintenance page rather than a working public app.

## Full List of Shortener Domains

The complete raw dataset lives in [list.txt](./list.txt).

That file includes 950+ known shortener domains and hostnames gathered from public services, historical providers, branded short domains, and services used by apps or publishers. It is useful for:

- Link expansion and unshortening tools.
- Security, redirect, and phishing research.
- Building allowlists or denylists for shortener domains.
